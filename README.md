# Projeto PDV em C#

Sistema de Ponto de Venda (PDV) desenvolvido em C# como projeto acadêmico de avaliação final do semestre, com foco na aplicação prática de lógica de programação, orientação a objetos e regras básicas de um fluxo comercial.

## Objetivo do projeto

O objetivo deste projeto é simular o funcionamento básico de um sistema de vendas, permitindo o cadastro e controle de produtos, realização de vendas e aplicação de regras simples relacionadas ao processo de atendimento em um comércio.

## Funcionalidades

- Cadastro de produtos
- Consulta de produtos
- Registro de vendas
- Controle básico do fluxo de venda
- Aplicação de lógica de negócio
- Organização do código com base em orientação a objetos

## Tecnologias utilizadas

- C#
- .NET
- Programação Orientada a Objetos
- Lógica de Programação
- Conceitos de sistemas comerciais / PDV

## Conceitos aplicados

Durante o desenvolvimento do projeto, foram aplicados conceitos importantes para a construção de sistemas, como:

- Criação e manipulação de classes
- Separação de responsabilidades
- Encapsulamento
- Estruturas condicionais
- Estruturas de repetição
- Manipulação de dados
- Regras básicas de negócio

## Contexto acadêmico

Este projeto foi desenvolvido como avaliação final de disciplina, com o objetivo de demonstrar os conhecimentos adquiridos ao longo do semestre na construção de uma aplicação com lógica de negócio aplicada a um cenário próximo ao real.
